# Personal research website — GitHub Pages

This repository serves two separate public surfaces:

- **GitHub profile Overview:** [README.md](README.md) — concise introduction and four highlighted projects.
- **Research website:** [docs/index.html](docs/index.html) — full academic and engineering portfolio.

## Publishing the website

GitHub Pages requires one repository setting that must be enabled by an account administrator:

1. Open **Settings → Pages** for [hongzzang-Lab/hongzzang-Lab](https://github.com/hongzzang-Lab/hongzzang-Lab/settings/pages).
2. In **Build and deployment**, choose **Deploy from a branch**.
3. Select **Branch: main**, **Folder: /docs**, then click **Save**.
4. Once GitHub confirms publication, the project-site address should be:
   **https://hongzzang-lab.github.io/hongzzang-Lab/**

The site address is a predicted GitHub Pages project URL; it is **not evidence that publishing has already been enabled**.
